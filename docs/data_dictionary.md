# Data dictionary

All data is **synthetic**, generated by `src/generate_synthetic_data.py` from a
fixed random seed. Court names, regions, volumes and durations are invented.

## `data/raw/cases_raw.csv` — 4,238 rows

The source extract, in the state these files usually arrive in. Never modified.

| Column | Type | Meant to be | Actually arrives as |
|---|---|---|---|
| `case_id` | text | Unique case reference | Six digits with leading zeros (`002866`). Read as a number, it loses them. 38 IDs appear twice |
| `court_id` | text | Foreign key to `courts.csv` | Two-digit text. Some blank, some `Unknown`, 22 pointing at courts that do not exist |
| `case_type` | text | Family / Youth / Civil / Criminal | **21 distinct values** — casing, whitespace, and abbreviations (`Fam`, `Yth`, `Crim`) |
| `filed_date` | text | Date filed | `dd/mm/yyyy`. A US-default parse corrupts the 1st–12th of each month |
| `disposed_date` | text | Date disposed | Same format. **Blank means the case is still open** — information, not a defect |
| `status` | text | Active / Disposed | Seven variants of two values |
| `reported_days` | text | Duration as recorded by the source system | Text with stray whitespace, `N/A`, `-`. Disagrees with the dates for 47 cases |

## `data/raw/courts.csv` — 12 rows

| Column | Type | Description |
|---|---|---|
| `court_id` | text | Primary key |
| `court_name` | text | Invented court name |
| `region` | text | Northern / Central / Eastern / Southern |
| `court_type` | text | District or High |

## `data/processed/cases_clean.csv`

One row per case. Source columns above, cleaned, plus:

| Column | Type | Description |
|---|---|---|
| `waiting_days` | int | Filing to disposal. Null for open cases |
| `days_open` | int | Filing to the reporting date. Null for closed cases |
| `is_open` | bool | No disposal date recorded |
| `overdue` | bool | Open longer than 365 days |
| `age_band` | category | 0–3 months / 3–12 months / 12+ months. Open cases only |
| `filed_month` | text | `YYYY-MM` |
| `filed_quarter` | text | `YYYYQn` |
| `disposed_month` | text | `YYYY-MM` |
| `quality_flag` | bool | **True = excluded from analysis** |
| `quality_reason` | text | Why it was flagged |
| `duration_mismatch` | bool | `reported_days` disagrees with `waiting_days` |
| `court_name`, `region`, `court_type` | text | Joined from the lookup |

## Result tables

| File | Grain | Contents |
|---|---|---|
| `summary_by_region.csv` | one row per region | Closed count, median / mean / p75 days, open count, overdue count and % |
| `summary_by_court.csv` | one row per court | Same, by court, with region and court type |
| `monthly_flow.csv` | one row per month | Filings, disposals, net change |
| `backlog_age_profile.csv` | one row per region per band | Open case counts, suppressed below 5 |
| `disposal_time_by_quarter.csv` | one row per region per filing quarter | Filed, closed, closure rate, median days, `complete` flag |
| `cleaning_log.csv` | one row per decision | Issue, rows affected, decision, reason |

## Suppression

Any count or median resting on fewer than **5** cases is blanked. See
`docs/methodology.md` for why, and for the limits of a simple cell threshold.
